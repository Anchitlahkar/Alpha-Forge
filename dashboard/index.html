EOS Token Mismatch in On-Policy Distillation

AI Research · Hugging Face Papers

A new paper identifies that length inflation in on-policy distillation (OPD) often stems from a mismatch in how student and teacher models handle end-of-sequence (EOS) tokens, even when their declared stopping sets are identical. Treating functionally equivalent EOS tokens as a single semantic stopping action reduces this problem, though other factors can still cause late-stage length growth.

  • On-policy distillation (OPD) can cause 'length inflation,' where student models generate thousands of redundant tokens after the correct answer.
  • A key cause is a 'termination-token mismatch' where base students and post-trained teachers prefer different EOS tokens, even if their official stopping sets are the same.
  • This mismatch suppresses the student's preferred termination without reliably transferring the teacher's alternative.

Netflix Releases 'ja' Java Development Tools

Software Engineering · Netflix Tech Blog

Netflix released `ja`, a suite of composable command line tools designed to simplify modern Java development, particularly with the Java Module System, integrating with Maven, and enhancing module integrity.

  • Netflix introduced `ja`, a family of composable command line tools for modern Java development, building on the Java Module System.
  • `ja` makes the module descriptor a complete project description, including dependency versions and module metadata.
  • The `ja` suite includes `jig` for module version resolution and Maven integration, `jfmt` for source formatting, `jist` for source-aware symbol search, and `jdocserver` for local API documentation.
