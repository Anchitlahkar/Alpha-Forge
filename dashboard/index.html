Incentivizing Self-Learning in Large Language Models via Reinforcement Learning

8.45Ranked

AI Research · Hugging Face Papers · signal 8.0/10

Researchers used reinforcement learning and a `BookNavigator` interface to teach large language models to self-learn from textbooks, increasing one model's math proof accuracy from 51.5% to 79.5%.

So what

Large language models can now learn new subjects from long-form texts like textbooks, improving their ability to solve problems in unfamiliar domains. This makes them more adaptable beyond their initial training data.

Key points

  • Large language models (LLMs) can now self-learn by autonomously retrieving, studying, and applying knowledge from long-form reference materials.
  • Researchers created a textbook-based mathematical problem-solving task to test this capability.
  • A `BookNavigator` interface helps LLMs navigate textbook content.
  • Reinforcement learning (RL) with fine-grained rewards incentivizes the self-learning process.
  • The method raised `Intern-S2-Preview-35B`'s proof accuracy from 51.5% to 79.5%.

Worth doing

  • Read the paper `arxiv:2610.39671` to understand the `BookNavigator` interface and RL reward structure.
  • Look up Lingkai Kong, the lead author, to see their other work.
  • Check the `hf papers read 2610.39671` command if you use the Hugging Face CLI.

Read Less, Solve More: Token-Efficient Sparse Reading of External Content for AI Agents

AI Research · Hugging Face Papers

AI agents often read entire documents, increasing costs. SparseRead is a new control layer that reduces token use by up to 92.9% and wall time by up to 89.0% without losing task quality.

  • AI agents frequently access web pages, documents, and tool responses, often reading entire objects when only sparse evidence is needed.
  • This over-reading increases token and latency costs, and can dilute relevant evidence.
  • SparseRead is a reusable reading control layer that governs content admission without modifying the agent model.
