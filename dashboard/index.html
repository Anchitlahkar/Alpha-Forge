YuE2: Unifying Symbolic and Audio Music Generation at Frontier Quality

9.15Ranked

AI Research · Hugging Face Papers · signal 9.0/10

YuE2 unifies symbolic and audio music generation, producing editable scores and full songs. It outperforms public baselines and rivals proprietary systems like Suno v5.

So what

This model advances AI's ability to create music with both structural control and high-fidelity audio. It also enables new forms of agentic music editing.

Key points

  • YuE2 unifies symbolic and audio music generation through symbolic planning.
  • It uses an AR-NAR Mixture-of-Transformers (MoT) to first write a readable score, then expand it into semantic music tokens, and finally realize it as full-song audio.
  • Expert listeners preferred symbolic planning for overall quality, with 49.3% preference versus 34.6% without planning.
  • YuE2 scored 6.73 on WildSongBench's SongBench Global Avg, exceeding all evaluated public baselines.
  • It rivals proprietary song generators, with best-of-8 selections favored over Suno v4.5 and nearly balanced preferences against Suno v5.

Self-Evolving Coding Agents: From Digital Programs to Physical-World Intelligence

AI Research · Hugging Face Papers

Researchers propose Physical Coding, a new paradigm for AI agents to represent task state and execution as code, enabling self-evolution and improved performance in physical-world robotics.

  • Current vision-language-action (VLA) and world-action (WAM) models struggle with generalization and long-horizon tasks because task requirements are implicitly encoded in action sequences.
  • The paper introduces Physical Coding, a method that represents task state and execution as explicit code, similar to how large language models (LLMs) use code for digital tasks.
  • Physical Coding consists of two parts: Code as World, which records objects, relations, constraints, and progress, and Code as Policy, which organizes planning, verification, recovery, and execution.

Improving Test-Time Scaling with Adaptive Looped Transformers

AI Research · Hugging Face Papers

Researchers introduced TaH2, an adaptive looped transformer that improves test-time scaling for AI models. It achieves a 53% better accuracy-compute slope and higher peak accuracy than non-looped baselines by dynamically allocating computation.

  • Looped transformers reuse layers for latent computation, offering parameter efficiency.
  • Existing looped transformers often show steeper accuracy-compute slopes but underperform non-looped models at matched compute.
  • Fixed-depth looping wastes computation on tokens that do not benefit from extra iterations.
