World In-Context Learning for Agentic Robot Manipulation

8.8Ranked

AI Research · Hugging Face Papers · signal 8.5/10

Researchers introduced World In-Context Learning (WICL) and RoboScript, an infrastructure that enables robots to learn manipulation tasks from one demonstration in simulation and apply them to real-world scenarios, achieving 83.4% success on RoboTwin 2.0 tasks.

So what

Robots can now learn complex manipulation tasks from a single demonstration and generalize them to new environments. This approach allows for more adaptable and efficient robotic systems.

Key points

  • Traditional trained action policies tie learned skills to network weights, limiting generalization to the distribution they were trained on.
  • In-context learning (ICL) avoids this coupling but has not matched trained policies due to a lack of real-world feedback in demonstrations.
  • The new World In-Context Learning (WICL) paradigm allows a frozen model to rehearse a task in a simulator and write feedback into its context, not its weights.
  • RoboScript, a modular infrastructure, implements WICL for agentic manipulation.
  • From a single demonstration, RoboScript learns tasks through simulation rehearsal, stores knowledge as Task Memory, and deploys it on new scenes.

  • Look up the RoboScript GitHub repository at github.com/ArcheOne-AI/RoboScript.

DepthGraft: Structural Regularization through Hierarchical Cross-Layer KV Reconstruction

AI Research · Hugging Face Papers

DepthGraft improves deep language models. It shares key-value representations across layers, reducing memory by one third and boosting accuracy on models up to 16B parameters.

  • DepthGraft is a hierarchical KV-sharing architecture that improves deep language model training.
  • It addresses depth-wise information dilution in Pre-LN architectures by reusing key-value (KV) representations across layers.
  • This method creates direct gradient paths, acting as an implicit structural regularizer for KV representation geometry.

Time Running Backwards, and Where It Stops: Superoscillations of Proper Time and the Memory of the Environment

Quantum Computing · arXiv quant-ph

A quantum system prepared in a superposition of proper times can be post-selected to evolve for a negative or amplified duration, acting as a quantum time-translation machine. Reversing irreversible processes like atomic decay with this machine is limited by the environment's memory time and bandwidth, not entropy.

  • A quantum system in a superposition of proper times evolves for different durations in each branch.
  • Post-selecting the control creates a superoscillation of the time-dilation factor, allowing the system to evolve for an effective proper time that can be negative, zero, or exceed unity.
  • This effect is called the quantum time-translation machine, originally proposed by Aharonov, Anandan, Popescu, and Vaidman.
