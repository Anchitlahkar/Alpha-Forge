Long-WAM: Scaling Context for Robot Control

8.38Ranked

AI Research · Hugging Face Papers · signal 8.0/10

Long-WAM is a new model-system framework designed to scale the context of world-action models for real-time robot control. It uses autoregressive pretraining to process longer visual histories, boosting robot task success rates and enabling deployment on various hardware.

So what

Real-time robot control can now use longer visual histories without action delays. This improves task success rates and enables more complex, dynamic manipulations.

Key points

  • Long-WAM is a model-system framework for scaling causal world-action models under real-time control constraints.
  • Autoregressively pretrained video foundation models are key to effectively using longer visual histories for robot control.
  • Increasing context from 0.0 to 19.2 seconds on RoboCasa GR-1 raised success from 63.3% to 78.7%.
  • Long-WAM achieved the best results among compared methods on LIBERO-Long, RoboTwin2.0, and DOMINO benchmarks.
  • It deploys on RTX 5090, DGX Spark, and Jetson AGX Thor, with each action chunk taking 107.4ms on RTX 5090.

R-Quest: Sustaining Self-Evolution in Reasoning Models

AI Research · Hugging Face Papers

Self-evolving AI models often suffer performance collapse due to invalid and repetitive self-generated questions. Researchers introduced R-Quest, a method that uses validity and novelty feedback to guide self-evolution, achieving superior and stable performance across various reasoning tasks.

  • Self-evolving reasoning models, which learn from their own generated questions, can experience performance collapse during repeated self-training.
  • Analysis identified two core problems: invalid questions becoming prevalent and existing diversity controls failing to detect mathematically equivalent but lexically different questions.
  • Invalid questions increase across training rounds, and answer-consistency filtering exacerbates their proportion in training data.

STEPQuant: Recurrent State Quantization Framework

AI Research · Hugging Face Papers

Researchers developed STEPQuant, a post-training quantization framework for linear attention recurrent states. It significantly reduces memory usage by up to 68.7% and achieves over 5x compression while maintaining near FP32 accuracy with 6-bit states.

  • Linear attention models use fixed-size recurrent states, which can be a memory bottleneck during concurrent serving.
  • Directly quantizing these states to low precision often causes severe accuracy degradation due to error propagation.
  • The impact of quantization errors depends on temporal (long-lived memory) and spatial (key-row impact) dimensions.
