Trajectory2Gym: Decision-Grounded Compositional Interaction Synthesis for Tool-Use Agents

7.67Ranked

AI Research · Hugging Face Papers · signal 7.0/10

Researchers introduced Trajectory2Gym, a new method that significantly improves the training of tool-use agents by creating interactions with compositional coverage and decision grounding. This approach has led to performance gains of 16.9-29.8 percentage points on relevant benchmarks.

So what

Training AI agents to use tools effectively requires carefully constructed interactions, not just collecting successful examples. This method improves agent performance by focusing on learnable decisions and multi-step dependencies.

Key points

  • Successful tool-use trajectories often lack compositional coverage or decision grounding, making them poor training data.
  • Trajectory2Gym constructs executable interactions that represent multi-step dependencies and uses only decisions supported by the agent's visible history.
  • The method uses structural-support selection and parent-normalized supervised fine-tuning.
  • It improves Tau1, Tau2, and BFCL benchmarks by 16.9 to 29.8 percentage points across five Qwen3 model scales.
  • Performance gains are highest in stateful and multi-turn interactions.

Worth doing

  • Read the paper arxiv:2610.33568 to understand the Trajectory2Gym framework.
  • Look up the GitHub repository associated with Trajectory2Gym for implementation details.
  • Search for Yihao Hu to see related work on tool-use agents.

StreamVibe: Proactive Video Agents for Evolving User Intent

AI Research · Hugging Face Papers

StreamVibe is a new initiative that includes a benchmark, a streaming vision-language model, and a hierarchical memory system. Its goal is to enable proactive, intent-aware interaction for video agents, allowing them to adapt to implicit and evolving user goals.

  • Existing vision-language models often rely on explicit requests and fail to update their understanding as user intents change.
  • StreamVibe-Bench is a new benchmark with 4.1K evaluation samples and 85K training samples, covering explicit, implicit, and dynamic user intents.
  • StreamVibe-VL is a streaming proactive model that infers implicit user intents from continuous observations and dynamically tailors interactions as intents evolve.

InteractiveWorld: A Verifiable Human-Centric Environment for Building Better Interactive MLLM Assistants

AI Research · Hugging Face Papers

Researchers have introduced InteractiveWorld, a verifiable simulation environment, along with a benchmark called InteractiveBench. This platform evaluates the effectiveness of multimodal language models (MLLMs) in guiding humans through physical tasks, revealing that current MLLMs perform poorly, with the best model achieving only 25% on planning tasks.

  • InteractiveWorld is the first verifiable environment for closed-loop interaction, which means continuous feedback, between a human and an AI assistant.
  • It simulates an AI assistant guiding a human agent who observes the scene, understands instructions, and acts independently.
  • InteractiveBench is a dynamic benchmark with 120 multi-turn tasks across six categories.
