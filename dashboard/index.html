JEPA-Anything: Learning Predictive Models across Different Worlds

8.45Ranked

AI Research · Hugging Face Papers · signal 8.0/10

Researchers introduced JEPA-Anything, a domain-agnostic AI framework using orthogonal predictive factorization (OPF) to build world models that predict outcomes across seven different scientific and real-world domains, showing improved performance over existing baselines.

So what

A single AI framework can now predict dynamics across diverse domains like biology, physics, and vision. This advances the goal of general AI that understands and interacts with many types of systems.

Key points

  • JEPA-Anything is a domain-agnostic framework for world modeling.
  • It uses orthogonal predictive factorization (OPF), which extends joint-embedding predictive architectures (JEPA) by decomposing latent targets into complementary factors.
  • The framework was evaluated across seven domains: vision, biology, clinical trajectories, control, molecular dynamics, physical fields, and weather.
  • It improved reported metrics on all 10 dynamics tasks compared to JEPA baselines.
  • JEPA-Anything reduced single-intervention prediction error on Interventional Pong by 34.8%.

Worth doing

  • Read the paper arxiv:2609.20800.
  • Clone the repository at github.com/Gen-Verse/JEPA-Anything.
  • Look up Taoyong Cui, the first author.
