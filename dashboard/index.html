K2-Horizon: A Frontier Fleet of Open Source Language Models

8.45Ranked

AI Research · Hugging Face Papers · signal 8.0/10

The K2-Horizon project released a fleet of six open language models, from 0.9B to 375B-A23B Mixture-of-Experts (MoE), competitive on agentic and coding tasks. They introduce Mixture-of-Value Attention (MoVA) and Uno lossless diffusion adapters for efficiency and speed, and provide full development history and pipelines for transparency.

So what

New open language models with novel architectures and full transparency are available. This allows for deeper understanding and faster iteration on AI development.

Key points

  • K2-Horizon is a fleet of six fully open language models, ranging from 0.9 billion to 375 billion parameters (with 23 billion active parameters for the MoE model).
  • These models perform competitively with other open models of their size on agentic and coding benchmarks.
  • Mixture-of-Value Attention (MoVA), which applies MoE to attention value projections, and softplus attention gating are new techniques introduced to strengthen reasoning.
  • A 36B-A4B model using both MoVA and softplus gating nearly matches a 32B dense model trained on the same data, using one-seventh the active parameters.
  • Uno, lossless diffusion adapters, speeds up decoding by up to 2.2 times without needing a separate draft model.

Worth doing

  • Look up the K2-Horizon project page at https://ifm.ai/k2/.
  • Read the paper arxiv:2611.21003.

SPILLWAY: Separating Target Admission from Sanitization to Defend Tool-Using Agents against Prompt Injection

AI Research · Hugging Face Papers

SPILLWAY is a new defense mechanism that protects tool-using AI agents from prompt injection attacks by separating target admission from sanitization, achieving near-zero attack success with minimal overhead.

  • SPILLWAY defends tool-using AI agents against prompt injection attacks by separating target admission from sanitization.
  • It uses a deterministic check that admits an action's recipient, account, or URL if it appears in your request or a typed field from a read-only tool.
  • Addresses found only in free text, like an email body, are refused unless your request explicitly delegates them.

SWE-CoWork: Benchmarking Coding Agents as Digital Employees in Organizations

AI Research · Hugging Face Papers

A new benchmark, SWE-CoWork, evaluates AI coding agents in simulated software organizations, revealing they complete fewer than 8% of assignments despite partial test success, primarily failing at requirement tracking.

  • SWE-CoWork is a benchmark with 101 development assignments across 101 real repositories, 11 programming languages, and 12 application domains.
  • Each assignment places an agent in a simulated engineering organization with 26 colleagues.
  • Agents must recover requirements distributed across colleagues and workplace records, reconcile conflicting evidence, and implement changes.
8.15 AllocFlow: End-to-End Portfolio Trading Action Generation from Raw Market Data

Researchers developed AllocFlow, an end-to-end flow-matching framework that uses a cross-asset flow Transformer and a two-stage reinforcement learning process to generate portfolio allocations directly from raw market data. It improved risk-adjusted returns on cryptocurrency perpetual futures, raising annualized net return from 27.79% to 51.38%.

7.67 InclusionMed: Benchmarking AI for Inclusive Healthcare

InclusionMed is an open initiative to evaluate medical AI, introducing the InclusionMed Atlas for organizing benchmarks and the InclusionMed Index for scoring models. Initial findings show that model rankings and inference costs vary significantly by healthcare context, and models perform better on patient communication than clinical decision-making.
