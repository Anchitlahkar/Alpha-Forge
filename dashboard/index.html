So what

Advanced AI models can now design experiments and communicate uncertainty, making them more reliable partners in scientific discovery. This capability could accelerate scientific progress and make AI-driven research more trustworthy.

Key points

  • Shenzhen Loop Area Institute released AscendGYM, a kernel optimization benchmark for Huawei Ascend NPUs, to help AI develop custom kernels.
  • AscendGYM includes AscendForge, which provides unified interfaces for compilation, correctness checking, performance measurement, and feedback.
  • In tests, Opus 5, GPT-5.6, and GLM-5.3 showed strong performance in optimizing Ascend chips; Claude Code yielded the best absolute scores.
  • Lawrence Livermore National Laboratory researchers introduced SciResearch-Eval, a benchmark testing AI agents' ability to design experiments and report results with 95% uncertainty intervals.
  • SciResearch-Eval uses a deliberately flawed simulator to test AI's resilience to unanticipated equipment issues.
