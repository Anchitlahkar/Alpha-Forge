QEDist Software for Quantum Code Distance Certification

9.15Ranked

Quantum Computing · arXiv quant-ph · 18 Nov · signal 9.0/10

QEDist is a new software package that offers practical and exact distance certification for qubit stabilizer codes. It provides orders-of-magnitude speedups, making exact distance certification a viable tool for the selection and optimization of quantum codes.

So what

Practical exact distance certification helps you select and optimize finite-length quantum codes. This directly improves the feasibility and performance of future fault-tolerant quantum computers.

Key points

  • QEDist is a method and software package that certifies the exact distance of qubit stabilizer codes.
  • It builds on tree-search methods, constructing candidate logical operators one qubit at a time.
  • The method uses sparse parity checks, stabilizer equivalence, and verified symmetries to reduce work.
  • QEDist prunes search branches by lower-bounding the weight needed to complete a logical operator, reducing search time.
  • It works for Calderbank-Shor-Steane (CSS) and non-CSS codes, and for the fault distance of syndrome-extraction circuits.

  • Look up the QEDist software package to see if a public repository is available.
  • Search for the authors of this paper to find related work or implementations.

Multi-Branch Transformer Architecture

AI Research · Hugging Face Papers

The Multi-Branch Transformer (MBT) is a new architecture designed to scale language models by processing inputs through parallel, independently parameterized branches. This approach, particularly when combined with shared KV caching, enhances model quality and inference efficiency, resulting in reduced training compute and increased decoding throughput.

  • Multi-Branch Transformer (MBT) scales language models using parallel, independently parameterized branches of sequential blocks.
  • It processes input through shared initial layers, executes branches in parallel, and fuses their outputs before shared final layers.
  • The Joint-KV method constructs a shared KV cache from branch representations at each depth for better inference efficiency.
