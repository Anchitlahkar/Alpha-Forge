Computing with qLDPC Codes by Climbing the Chain Map Hierarchy

9.22Ranked

Quantum Computing · arXiv quant-ph · 4 Sep · signal 9.0/10

Researchers developed the "chain map hierarchy," a new framework that unifies logical Pauli, Clifford, and non-Clifford operations for qLDPC codes, enabling the discovery of new constant-depth quantum gates.

So what

Building fault-tolerant quantum computers requires efficient logical operations. This framework simplifies the discovery and design of these operations, potentially speeding up the development of practical quantum computing.

Key points

  • A new framework, the "chain map hierarchy," unifies the description of logical Pauli, Clifford, and non-Clifford operations on qLDPC codes.
  • This framework provides a tool to discover new logical gates by applying intuition from Pauli logicals.
  • Researchers used this strategy to find constant-depth unitary implementations of the full logical Clifford group on any number of blocks of the 2D toric code.
  • They also found addressable logical CCZ gates on any triple of logical qubits on any number of blocks of the 3D toric code.
  • The chain map hierarchy extends other logical gadget constructions, offering a universal parameterization of cup products.

Worth doing

  • Look up the concept of the "chain map hierarchy" in quantum error correction.

AI Research · Hugging Face Papers

  • LLaDA-Image is a unified framework that pairs a 6B Diffusion Transformer (DiT) with a frozen vision-language understanding module built on the LLaDA2.0-Mini diffusion language model backbone.
  • It uses image-only pre-training and mid-training with 220 million samples, 98% of which are real images.
  • The model employs parameter-free RMSNorm and the Muon optimizer for efficient training.

Random Attention: Rethinking KV Cache Eviction for Efficient Reasoning

AI Research · Hugging Face Papers

A new method called Random Attention simplifies KV cache eviction for large language models by keeping the prompt and randomly evicting other tokens. This approach matches or exceeds complex scoring methods while delivering 32-43% higher throughput in vLLM deployment.

  • Large language models performing extended reasoning face a KV cache memory bottleneck.
  • Existing KV cache compression methods score each cached token to decide what to keep.
  • Random Attention keeps the prompt and evicts tokens uniformly at random within each attention head, computing no score.
