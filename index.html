OpenGCUA: Toward a Fully Open Stack for Generalist Computer Use

8.45Ranked

AI Research · Hugging Face Papers · signal 8.0/10

OpenGCUA introduces an open-source full stack for generalist computer-use agents (GCUAs), integrating visual and programmatic interfaces, code execution, and harness-to-model decision transfer. It improves task performance and efficiency across 8 frontier models on OSWorld-v2, and includes a real-device harness and cross-device SDK.

So what

Open-sourcing a full stack for generalist computer-use agents allows for community-driven development and systematic study of these systems. This could accelerate progress in AI agents that interact with computers through both visual and programmatic interfaces.

Key points

  • OpenGCUA is an ongoing project to develop and open the full stack for generalist computer-use agents (GCUAs) with the community.
  • A GCUA is a system where the model chooses how to observe, act, and organize its work across visual and programmatic interfaces.
  • The agent design incorporates code execution and harness-to-model decision transfer, moving workflow decisions from fixed rules to the model.
  • On OSWorld-v2, OpenGCUA improved task scores for 8 models, including GPT-6 Astra and Claude Opus 5, raising the mean partial score by 19.6 points and reducing steps per task by 53.0%.
  • The first release includes the technical report, GCUA design, evaluation trajectories from 8 models, a real-device harness for macOS, and a cross-device SDK.

Worth doing

  • Read the technical report at arxiv.org/abs/2610.22200.
  • Clone the GitHub repository at github.com/Tongyi-MAI/OpenGCUA.
  • Try the interactive lab at tongyi-mai.github.io/OpenGCUA.
